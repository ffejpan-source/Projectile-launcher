# Projectile-launcher
Program that simulates a projectile launcher with no air resistance
A Python simulator that calculates and visualizes projectile trajectories using basic kinematics. Enter a launch angle and velocity, and it plots the resulting arc. 
Supports comparing multiple launches on the same graph.
Setup: pip install matplotlib ; run it with py projectile.py  Enter how many launches you want to compare, with an angle and velocity for each one
